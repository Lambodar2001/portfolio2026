\# Premium 3D Web Development



When building 3D websites:



\## Core Stack



Prefer:

\- React + TypeScript

\- Three.js

\- React Three Fiber

\- @react-three/drei

\- Framer Motion

\- GSAP when advanced timeline/scroll animation is required

\- Tailwind CSS

\- GLTF/GLB for optimized 3D assets



\## Design Principles



Create premium, modern interfaces inspired by high-end AI/SaaS websites.



Prioritize:

\- Strong visual hierarchy

\- Minimal UI

\- Smooth animations

\- Excellent typography

\- Subtle lighting

\- Cinematic 3D scenes

\- Responsive design

\- Fast loading

\- Professional spacing



Avoid:

\- Excessive 3D effects

\- Random floating objects

\- Heavy animations everywhere

\- Generic templates

\- Unnecessary gradients

\- Poor mobile performance



\## Three.js Guidelines



Use React Three Fiber for React projects.



Use Drei helpers whenever appropriate.



Keep 3D components modular.



Optimize:

\- geometry

\- textures

\- lighting

\- DPR

\- shadows

\- model size

\- animation loops



Use lazy loading for heavy 3D assets.



Prefer GLB/GLTF models.



\## Animation



Use Framer Motion for UI transitions.



Use GSAP when complex timeline or scroll-based animation is required.



Animations should feel:

\- smooth

\- intentional

\- premium

\- subtle



Avoid excessive bouncing or distracting motion.



\## Performance



Always consider:

\- mobile devices

\- GPU usage

\- memory consumption

\- unnecessary re-renders

\- asset compression

\- lazy loading



Do not sacrifice usability for visual effects.



\## Code Quality



Use:

\- reusable components

\- TypeScript types

\- clean folder structure

\- hooks for reusable behavior

\- meaningful component names



Before adding a dependency, check whether the existing stack already provides the required functionality.
